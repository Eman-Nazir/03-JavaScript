## 🧭 Learning Architecture

The repo is organized as a day-by-day progression through JavaScript — each phase builds directly on the last.

```
PHASE 1 · CORE FUNDAMENTALS (Day 1–9)
  Variables, operators, functions, scope, arrays, loops, callbacks
        │
        ▼
PHASE 2 · OBJECTS & ARRAY METHODS (Day 10–15)
  Objects, manual array methods, forEach, map & filter, debugging scopes
        │
        ▼
PHASE 3 · DOM, EVENTS & BOM (Day 16–28)
  DOM selection & traversal, event listeners, form handling, mini projects,
  Browser Object Model (history, location, load events)
        │
        ▼
PHASE 4 · ES6+ & MODULES (Day 29–31)
  ES6 syntax, modules, Promises, a quiz app built on ES6 modules
        │
        ▼
PHASE 5 · ASYNC JS & APIs (Day 33–37)
  Async/Await, Fetch API, Promises with real endpoints, debounce & throttle
        │
        ▼
PHASE 6 · OOP & ADVANCED CONCEPTS (Day 38–58)
  Prototypes, RegEx, closures & lexical scope, memory management,
  classes, encapsulation, mixins, method chaining, polymorphism, inheritance
```

## 🛠️ Concepts Covered

- **Fundamentals:** data types, variables, operators, functions, scope, loops
- **Data Structures:** arrays, objects, array methods (`map`, `filter`, `forEach`)
- **Browser APIs:** DOM manipulation & traversal, event listeners, BOM (history, location)
- **Modern JS:** ES6 syntax, modules, Promises, Async/Await, Fetch API
- **Performance:** debounce & throttle
- **OOP:** prototypes, classes, encapsulation, inheritance, polymorphism, mixins, closures
